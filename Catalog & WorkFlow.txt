## Video : 4

Parallel approval 
Parallel task

Branch
🔹 Why we use Branch

You use the Branch activity when you want to perform multiple actions at the same time, instead of one after another.
🔹 Example Use Case

Scenario:
You have a “New Laptop Request” catalog item.
After approval, you want to:

Create a task for IT Hardware to prepare the laptop.

Create a task for Software Team to install required software.

✅ Solution using Branch:

Add a Branch activity after the approval step.

Create two branches:

Branch 1: Create “Hardware Task”

Branch 2: Create “Software Task”

Both tasks run simultaneously, improving process efficiency.
